## 問題1：親画像の固定が効いていない

この生成は「マスターを1箇所だけ変えたもの」になっていません。別撮りに近い状態です。

マスターと重ね合わせて測りました。

| 測ったこと | 結果 |
| --- | --- |
| 顔まわりの残差（移動なし） | 42.4 |
| 平行移動を許した最良 | 21.7（dx -8px / dy +50px） |
| 拡縮も許した最良 | 13.1（**頭が約11%大きい** / dy +68px） |

**頭が1割ほど大きくなり、7センチ相当ぶん下がっています。**

比較として、まばたき版を作ったときは、目の外側では移動なしで残差がほぼ0でした。
あのときと同じ状態になっていません。

### なぜこれが問題か

まばたきと口パクは楕円マスクで部分上書きするので、マスクの外がずれても画面に
出ませんでした。**表情は切り抜き全体を差し替えます。**マスクがないので、ずれが
そのまま画面に出ます。この状態で採用すると、感情が変わるたびにMAYAが下にずれて
一回り大きくなります。

### 直し方

まばたきのときに効いた書き方を、表情にもそのまま使ってください。実績パイプラインの
プロンプトは「髪の毛一本」「眼鏡のブリッジ」「手の本数」まで名指しで固定してから
「両目だけを変える」と指示していました。表情でも同じ粒度で固定してください。

固定すると明示してほしいもの:

- 頭の大きさ、位置、画角、クロップ
- 生え際と髪の流れ。**前髪が眉にかかっている状態も含めて**そのまま
- 襟の形と開き具合、肩の位置
- ピアス、ネックレス
- 背景の色と均一さ
- ライティングの方向と強さ

変えてよいもの:

- **眉の角度と高さ**
- **口の形**
- 視線のわずかな向き

## 問題2：表情がchallengeになっていない

造作は変わりましたが、狙いの表情になっていません。

### 起きた変化（意図していないもの）

- **眉が太く濃くなった。**これは表情ではなく造作の変化です。マスターの眉の
  太さ・濃さのまま、角度と高さだけ変えてください
- **前髪が眉にかからなくなった。**髪型が変わっています。マスターのまま残して
  ください。眉に髪がかかっていても仕様上は問題ありません

### 起きていない変化（必要なもの）

- **片眉が上がっていない。**左右対称のままです。challengeは非対称が要です
- **口が笑みのまま。**片側だけ上げた含みのある笑みにしてください

### 狙いの表情

```
社長、それ本当にやります？
```

自信があって、少しからかっていて、頭が回る。この3つです。

- 片眉だけをわずかに上げる。上げすぎない
- 口角は片側だけ、わずかに上げる。歯は見せない
- 視線はまっすぐカメラへ。目をそらさない
- 偉そうにしない。見下していると見えたらやり直し
- 露骨に色っぽくしない。緊張感は視線と自信から出す

## 次の1枚で見ること

こちらで同じ測定をします。

1. 頭の大きさと位置がマスターと一致しているか（scale 1.00、dx dy が0付近）
2. 眉の太さと濃さがマスターのままか
3. 前髪が眉にかかった状態のままか
4. 片眉が上がっているか
5. 片側だけの笑みになっているか

1が通れば、残り8表情も同じ書き方で回せます。ここが今回の山場です。

出してもらえると、ここで分かったことがそのまま本番に使えます。今回の1086x1448は
マスターと同じ寸法なので、その点は問題ありません。
