## 問題2：表情がchallengeになっていない

造作は変わりましたが、狙いの表情になっていません。

### 起きた変化（意図していないもの）

- **眉が太く濃くなった。**これは表情ではなく造作の変化です。マスターの眉の
  太さ・濃さのまま、角度と高さだけ変えてください
- **前髪が眉にかからなくなった。**髪型が変わっています。マスターのまま残して
  ください。眉に髪がかかっていても仕様上は問題ありません

### 起きていない変化（必要なもの）

- **片眉が上がっていない。**左右対称のままです。challengeは非対称が要です
- **口が笑みのまま。**片側だけ上げた含みのある笑みにしてください

### 狙いの表情

```
社長、それ本当にやります？
```

自信があって、少しからかっていて、頭が回る。この3つです。

- 片眉だけをわずかに上げる。上げすぎない
- 口角は片側だけ、わずかに上げる。歯は見せない
- 視線はまっすぐカメラへ。目をそらさない
- 偉そうにしない。見下していると見えたらやり直し
- 露骨に色っぽくしない。緊張感は視線と自信から出す

## 次の1枚で見ること

1. 眉の太さと濃さがマスターのままか
2. 前髪が眉にかかった状態のままか
3. 片眉が上がっているか
4. 片側だけの笑みになっているか

頭の大きさと位置は見ません。

1が通れば、残り8表情も同じ書き方で回せます。ここが今回の山場です。
