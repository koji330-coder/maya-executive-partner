# MAYA 参照画像リクエスト（ChatGPT へそのまま貼る用）

---

## これは何の依頼か

MAYA というキャラクターはすでに確定しています。**描き直しや再デザインの依頼ではありません。**

確定済みの MAYA を、**下流の画像加工パイプラインで使える形の高解像度リファレンスとして描き起こす**依頼です。

## なぜ必要か

現在の参照は、以前作ってもらったキャラクター設定シート1枚（1536×1024）から切り出したものです。実測で以下の問題があります。

- 顔の参照が 287×412 しかない。identity reference としては解像度不足
- 表情一覧は8パネル横並びで、1パネルあたり約130px。参照として使えない
- シート全体に日本語コピー・ロゴ・パネル名が焼き込まれており、そのまま生成器に渡すと文字が出力に漏れる

## 一緒に渡すもの

| ファイル | 役割 |
| --- | --- |
| `maya-character-bible.png` | 確定済みのMAYA。デザインの基準 |
| `maya-safe-zone-diagram.png` | **目と口のセーフゾーンの図。仕様3の内容** |

## この画像が何に使われるか（これを踏まえて描いてください）

1. 人物を切り抜いて、背景と分離する
2. 目を3コマ（開 / 半開 / 閉）、口を3コマ（閉 / 小 / 開）に差分化する
3. その差分をアプリ内で切り替えて、まばたきと口パクをさせる
4. 差分は元画像とピクセル単位で一致している必要がある

つまり必要なのは「綺麗な絵」ではなく**「加工できる絵」**です。見栄えが良くても加工できない絵は使えません。

## 仕様（すべて必須）

### 1. 1リクエスト1枚。パネルを並べたシートにしない

設定シートは8つの表情を横一列に並べた構成で、1つあたり約130pxでした。**1枚のキャンバス全体を1カットに使ってください。**

### 2. 背景は完全な単色フラット

- 中間調のニュートラルグレー（#909090 前後）
- グラデーション、ボケ、室内風景、窓の外の夜景、光源演出をすべて排除
- 理由：**ダークブラウンの髪とアイボリーの服の両方**が背景から分離する必要があります。白背景だと服が溶け、暗い背景だと髪が溶けます
- グリーンバックは使わないでください（髪に色かぶりが出ます）

背景は後で別途用意したシーン画像に差し替えます。人物画像側に環境を描き込む必要はありません。

### 3. セーフゾーンは2段階 ← ここが今回の肝

**添付の図（`maya-safe-zone-diagram.png`）を必ず見てください。**

3つの枠がありますが、**厳しさが2段階に分かれています。同じ扱いにしないでください。**

#### 第1ゾーン（絶対厳守）── 目と口

- **目**: 左右それぞれの、まぶた・眼球・まつ毛・下まぶたと、**まぶたが下りる範囲**
- **口**: 鼻の下から顎の手前まで

この2つは、あとで丸ごと差し替えてまばたきと口パクを作ります。ここに、まぶたや唇と
一緒に動いてはいけないものが入っていると破綻します。

- 髪を1本も入れない
- 手や小物を入れない
- 強い影を落とさない
- 輪郭をぼかさない

#### 第2ゾーン（読めればよい）── 眉

**眉には髪がかかっても構いません。**

理由: **まばたきをしても眉は動きません。**眉にかかった髪は、動かない背景のような
ものなので、アニメーションを壊しません。

眉が必要なのは別の理由です。表情を伝えるのが眉だからです。挑発的なら片眉を上げ、
呆れなら眉を下げ、心配なら眉を寄せます。だから条件は「眉が隠れていないこと」ではなく、

**眉の形・内端・山が読めること**

これだけです。髪の束が横切っていても、眉がどう動いたか分かるなら問題ありません。

#### 髪型は変えないでください

前髪はMAYAの一部です。**眉にかかるのは構いません。目にかからなければ成立します。**

髪型・髪の量・毛流れを変える必要はありません。

#### 枠の外は、むしろ今まで通り豊かに描いてください

- 前髪、髪のボリューム、毛流れ
- 頬の赤み、肌の質感
- ピアス、ネックレス
- 衣装のディテール
- 顎より下の手

**「地味にしてほしい」という依頼ではありません。**制約がかかるのは目と口の周りだけで、
それ以外は今のクオリティを保ってほしい、という依頼です。

### 4. 髪の輪郭（切り抜きのため）

セーフゾーンとは別に、人物の外周にも条件があります。

- 髪の外形が背景に対して明確に分離していること
- 極細の飛び毛、毛先の透け、モーションブラーを避ける
- 逆光のリムライトで輪郭が溶けるのを避ける
- 髪型・髪色・長さは設定シートのまま変更しない

人物を背景から切り抜くため、輪郭が曖昧だと抜けません。**髪の量やシルエットは変えなくて
よく、輪郭がはっきりしていればよい**ということです。

### 5. 手の位置

確認したところ、**設定シートの8パネルすべてが頬杖**でした。ヒーローカットも同様です。
指が頬骨まで上がっていて、口のセーフゾーンにも近い状態です。

ただし頬杖そのものを禁止したいわけではありません。MAYAらしさの一部だと理解しています。

- **A（正面ニュートラル／マスター）だけは、両手を顔から完全に外してください。**
  すべての差分がこの1枚から切り出されるため、顔の前に何もない状態が必要です
- **それ以外のカットでは、手は顎より下であれば入れて構いません。**
  頬杖にするなら、指を頬骨まで上げず、顎の下で支える形にしてください

### 6. ライティング

- 顔に強い影を落とさない
- 片側だけ黒く潰れる照明にしない
- 被写界深度で輪郭をぼかさない（ぼけた輪郭は切り抜けません）

### 7. 文字を一切入れない

ロゴ、キャプション、ラベル、日本語コピー、ウォーターマーク、すべて不可です。アプリ内の文言はプログラム側で描画します。

### 8. 構図

- 縦長、3:4 または 4:5
- 胸上〜腰上（顔のドアップにしない。バストアップ程度）
- 人物は中央
- スマートフォンの画面で顔が十分読めるサイズ
- 可能な限り高解像度。書き出し後にリサイズや再圧縮をしないでください

### 9. カメラを全カットで揃える

複数枚作る場合、**画角・カメラ距離・目線の高さ・人物のスケールを全カットで統一**してください。後工程で並べて使うため、カットごとに顔の大きさや角度が変わると使えません。

## 依頼する枚数と順番

一度に全部作らないでください。前の1枚が確定してから次に進みます。

### 第1優先 — まずこの1枚だけ

**A. 正面ニュートラル（マスター）**

- 正面、または軽い3/4程度まで
- 口を自然に閉じる
- **両目を完全に開く**（半目・伏し目・目を細めるのは不可）
- 穏やかで、ごく軽く微笑む程度。歯を見せる笑顔にしない
- 視線はカメラへ
- 両手は顔から外す
- 上記1〜9をすべて満たす

**この1枚の出来が、アプリ全体のアニメーション品質の上限を決めます。**目と口のすべてのコマがこの画像から切り出されるためです。ここは時間をかけて構いません。

### 第2優先 — A が確定してから

**B. 斜め45度ニュートラル**
同一人物性の確認用。A と同じライティング、同じスケール、同じ服装。

**C. 全身正面**
服装とプロポーションの基準。デフォルト衣装（アイボリー〜白のトップス）。全身が入る構図。

### 第3優先 — B・C が確定してから

**D. 表情バリエーション（各1枚ずつ、フルキャンバス）**

`neutral` / `smile` / `thinking` / `serious` / `challenge` / `annoyed` / `happy` / `concerned` / `relaxed`

各表情の演出意図は別途渡します。第3優先に進む段階で共有します。

## 固定するキャラクター属性（変更不可）

- 成人女性、27歳
- 日本人
- ダークブラウンのロングヘア。長さも色も変えない
- 柔らかく知的な顔立ち
- 大きめだが自然な瞳
- 2.5D / 高品質モバイルゲーム調
- 写実的すぎない。かつアニメに寄りすぎない
- アイボリー〜白のビジネスカジュアルが基本
- ピアス・ネックレスは設定シートと同じものを維持するか、いっそ外す。**カットごとに変えない**

魅力のバランスは「可愛くて少し距離が近いが、中身は本物の経営参謀」です。

## やらないこと

- 顔が別人になる
- 髪型・髪色の変更
- 年齢が大きく上下する
- 欧米人風になる
- 完全な実写人物になる
- 萌えアニメ化する
- SFホログラム、サイバーパンク、青紫ネオンの「いかにもAI」表現
- 黒いビジネススーツ
- 過剰な露出、グラビア的・キャバクラ的なポーズ

## 提出前の自己チェック

A を出す前に、以下を自分で確認してください。

- [ ] 1枚のキャンバスに1カットだけか
- [ ] 背景は完全な単色か（グラデーション・ボケ・風景が入っていないか）
- [ ] **左右どちらの目にも、髪が1本もかかっていないか**
- [ ] まぶたが下りる範囲（眉と目の間の肌）にも髪がかかっていないか
- [ ] 口に髪も手もかかっていないか
- [ ] 両目が完全に開いているか
- [ ] 口が閉じているか
- [ ] 目と口に強い影が落ちていないか
- [ ] 眉の形・内端・山が読めるか（完全に見えている必要はない）
- [ ] 人物の外周（特に髪）が背景から分離しているか
- [ ] 輪郭がぼけていないか
- [ ] 文字が1文字も入っていないか
- [ ] 設定シートのMAYAと同一人物に見えるか
- [ ] 髪型を変えずに済んでいるか
- [ ] セーフゾーンの外は、設定シートと同じ描き込み量を保てているか

1つでも欠けていたら描き直してください。

特に次の3つは、後工程が成立しなくなるため妥協できません。

1. **左右どちらの目にも髪がかかっていない**こと
2. **両目が完全に開いている**こと
3. **人物の外周が背景から分離している**こと

眉に髪がかかるのは妥協ではなく、仕様上そもそも許容しています。
髪型を変えてまで眉を出す必要はありません。

逆に、最後のチェック項目も同じくらい大事です。セーフゾーンを守った結果、
のっぺりした絵になってしまったら、それは目的を外しています。**守るべきは
「今の魅力のまま、目と口の周りだけが整理されている」状態**です。

## 制約が満たせない場合

どうしても満たせない条件があれば、**黙って別の絵にせず、どれが満たせないかを言ってください。**
たとえば単色背景を保持できず必ず環境を描き込んでしまう、といった挙動があるなら、それを先に知りたいです。方式ごと変える判断材料になります。
