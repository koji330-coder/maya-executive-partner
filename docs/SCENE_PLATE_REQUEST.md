# シーン背景の制作依頼（そのまま貼る用）

---

## これは何の依頼か

iOSアプリ「MAYA」で、キャラクターの背後に敷く**背景だけ**の画像を5枚作る依頼です。

**人物は描かないでください。**キャラクターは別に用意した切り抜き画像を、アプリ側が
この背景の上に重ねます。

## 一緒に渡すもの

| ファイル | 役割 |
| --- | --- |
| `scene_work.webp` | **すでに完成している1枚目（work）。これが基準です** |

## いちばん大事なこと

**5枚は「別々の場所」ではなく、同じ部屋の時間帯と気分の違いです。**

利用者は同じキャラクターが同じ場所にいると感じる必要があります。朝も夜も、
オフィスも寛ぎのコーナーも、同じ建物の中にあるように見せてください。

添付の `scene_work.webp` が基準です。この部屋の素材感、壁の色、木の色、窓の位置感を
引き継いでください。家具の配置は変わって構いません。

---

## 全5枚に共通する仕様

### 1. 人も文字も入れない

- 人物、人影、シルエット、いっさい不可
- 文字、ロゴ、看板、数字、画面に映る文字、グラフの目盛り、すべて不可
- 画面やモニターを描く場合、中身は抽象的な形だけにしてください

### 2. 色

クリーム、アイボリー、温かいベージュ、やわらかいチャコール、くすんだゴールド。

**青と紫は使わないでください。**ネオンも不可。夜のシーンでも、光は電球色の
暖かい方向に寄せてください。

### 3. 構図

- **縦長 3:4**
- **画面の中央から上は静かに空けてください。**ここにキャラクターが立ちます
- 見どころは左右の端と下側に置いてください
- 全体をやわらかくぼかし、部屋を「細部」ではなく「気配」として見せてください

### 4. 質感

上質で静か。ストックフォト的な整いすぎた雰囲気にはしないでください。
写実と絵画の中間くらいです。

### 5. 納品

- PNG、生成された最大解像度のまま。リサイズ・再圧縮なし
- 1ファイル1枚

---

## 5枚の内訳

### 1. `work` — 執務中

**完成済み。作り直し不要です。**他の4枚の基準として添付しています。

### 2. `morning` — 朝

同じ部屋の朝。やわらかい自然光が入り、空気が澄んでいる。
1日が始まったばかりの、明るくて軽い感じ。

`work` より光量を上げ、影を浅く。

### 3. `strategy` — 戦略を練る

同じ空間の打ち合わせ寄りの一角。大きなディスプレイがあってよいが、
**映っているのは抽象的な形だけ**にしてください。数字も文字も不可です。

`work` より少し引き締まった空気。光をやや絞り、色温度を落ち着かせる。
それでも青には振らないでください。

### 4. `casual` — くつろぎ

同じ空間の、やわらかいラウンジの一角。ソファ、ラグ、低いテーブルなど。
仕事の場ではあるが、姿勢を崩して話せる場所。

`work` より暖かく、informal に。

### 5. `late_night` — 深夜

夜の役員室、または個人的なラウンジ。窓の外に東京のような街の灯り。
間接照明だけの、暖かく落ち着いた明るさ。

昼間より私的で、距離が近い雰囲気にしてください。**ただしそれは照明と奥行きで
出すものです。**ナイトクラブや寝室に見える設えにはしないでください。バーカウンター、
ベッド、過度に暗い赤や紫の照明は不可です。

窓の灯りは暖色寄りに。青白い夜景にしないでください。

## 提出前の自己チェック

- [ ] 人物・人影が1つも写っていないか
- [ ] 文字・数字・ロゴが1つも入っていないか
- [ ] 画面やグラフに読める内容が入っていないか
- [ ] 青や紫、ネオンが入っていないか
- [ ] 縦長 3:4 か
- [ ] 中央から上が空いているか（キャラクターが立つ場所）
- [ ] 添付の `work` と同じ部屋に見えるか

最後の項目がいちばん大事です。5枚を並べて、同じ場所の違う時間に見えなければ
やり直してください。
