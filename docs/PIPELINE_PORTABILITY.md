# パイプラインをどこからでも使えるようにする

Nano Banana のパイプラインは `クロノIT-動画制作リサーチ/nano-banana` にあり、
1台のマシンにしか存在しない。素材制作がその1台に縛られ、クラウドのセッションからは
触れない。これを解消する手順。

チェックリスト版: `https://claude.ai/code/artifact/97ef57df-aa9d-410b-a1ab-92fa10ed3905`

## 置き場所

`koji330-coder/character-motion-studio`。README 1行だけの空リポジトリで、
名前が用途と一致している。ここを本拠地にする。

## 手順

1. **そのフォルダが既に別のリポジトリの中か確認する。**
   `git -C <path> rev-parse --show-toplevel` が親フォルダを返す場合は、
   切り出し方の判断が要る。
2. **秘密が混ざっていないか見る。** `.env` の有無と、`AIza`（Google の API キーの
   頭）でのファイル検索。ヒットしたら環境変数から読む形に直してから上げる。
3. **`.gitignore` を置く。** `node_modules/`、`.env*`、出力画像のフォルダ。
   出力は再生成できるので上げない。
4. **push する。** 既存の README コミットの上に rebase して載せる。
5. **GitHub 上で2つ確認する。** 鍵が上がっていないこと。運用記録と `edit` の
   プロンプト実物（特に `lipsync-mask-review.md` とまばたき用プロンプト）が
   入っていること。後者がいちばん重要で、親画像を保持させる書き方の実物になる。
6. **API キーを環境変数に入れる。** チャットに貼らない。会話の記録に残る。
   この用途専用のキーを新しく発行し、環境の設定画面から渡す。
   参照: `https://code.claude.com/docs/en/claude-code-on-the-web`

## 到達性

Gemini のエンドポイントにはこのコンテナから到達できる。キーなしで叩くと Google
自身の `PERMISSION_DENIED`（APIキーがない）が返る。プロキシには止められていない。
足りないのはキーとパイプライン本体だけ。

## 揃ったあとの進め方

1. `doctor` を回す。API を呼ばないので課金なしで確認できる。
2. `lite` で最小のスモークテストを1回。このネットワーク経路でキーが通るかを見る。
3. まばたき用プロンプトの粒度を読み、表情用に書き直す。
4. `challenge` を作り直す。生成のたびにスケールとオフセットを測り、頭の大きさと
   位置がマスターと一致したものだけを採用候補にする。表情の出来を見るのはその後。

プロンプトの詰めは `lite`、通ってから本番設定で1回確認する。保持の挙動がモデル
階層で変わらないという賭けが入るが、最後の確認で拾える。
