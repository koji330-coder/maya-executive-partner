# 素材一覧

画面モックに寄せたあとの、必要な素材と未確定の要件。

`docs/ASSET_PIPELINE.md` が形式と置き場所、`docs/NANO_BANANA_PIPELINE.md` が
作り方、この文書が**何をいくつ作るか**です。

## 設計の変更点

**背景 × ポーズ × 表情の完全な掛け算をやめました。** 表情9 × ポーズ7 = 63枚に
瞬きの差分が付き、現実的ではありません。代わりに3階層にします。

| 階層 | 用途 | 背景 | 画面での割合 |
| --- | --- | --- | --- |
| Base | 通常会話・入力中 | 切り抜き＋プレート | 8割 |
| Reaction | 重要回答・感情表現 | 切り抜き＋プレート | 2割 |
| Scene | 時間帯の演出 | **焼き込み** | 開いた瞬間だけ |

Base と Reaction を切り抜きのまま残すのは、時間帯ぶんの複製を避けるためです。
焼き込むと表情ごとに時間帯の枚数が要ります。Scene は一枚絵なので焼き込みます。

## MAYAは1枚の立ち絵を切り取って見せている

Base と Reaction に別々の絵は要りません。**同じバストアップの切り抜きを、
どこまで残すかで4通りに見せています。**これが `StagePresentation` です。

| 表示 | 残す範囲 | 画面 |
| --- | --- | --- |
| `hero` | 全身 | ホーム |
| `chat` | 頭と肩 | 通常会話 |
| `input` | 顔だけ | キーボード表示中の小さな枠 |
| `reaction` | バストアップ | 重要回答の瞬間だけ |

拡大して戻すこと自体が演出になります。**2枚目の絵を描かずに反応が作れます。**

### B. Reaction のポーズ 5枚

いまの9表情は全部同じ立ち姿勢です。**顔だけで `annoyed` と `serious` を
区別しようとして失敗しました。**体が変われば区別が付きます。

| 表情 | ポーズ | 生成 |
| --- | --- | --- |
| `serious` | 腕を軽く組む | master + 瞬き + 口 = 3 |
| `challenge` | 少し前のめり | master + 瞬き + 口 = 3 |

そのまま乗ります。

## 未確定の要件

**素材を作るときに決めれば足りるもの**です。いま決める必要はありません。

### 1. Reaction の対象に `annoyed` を残すか

`src/features/character/useReactionSpotlight.ts` の `SPOTLIGHT_EMOTIONS` に
いまは入っています。キャラクターバイブルの看板表情だからです。

ただし現状 `serious` とほとんど区別が付きません。**拡大すると曖昧さが拡大
するだけかもしれません。** B の腕組みが出来てから、その大きさで見て決めます。

### 2. `surprised` を契約に足すか

モックのリアクション一覧にありますが、`MayaEmotion` は10値で `surprised` は
入っていません。足すなら `docs/AI_RESPONSE_CONTRACT.md` と
`docs/MAYA_CHARACTER_BIBLE.md` の変更になります。**先に仕様を直してから
プロンプトと絵を作ります。**

### 3. Base の表情をいくつ持つか

いまは9表情すべてが通常会話で切り替わります。1つに絞るとリアクションの落差が
最大になりますが、通常会話が固まります。**B のポーズが出来ると落差が体でも
付くので、そのあとに決めるのが正確です。**

### 4. `scene` をモデルに選ばせ続けるか

いまモデルは返答ごとに `scene` を返します。時間帯なら連続的に動いて自然
ですが、**場所が毎回変わると瞬間移動します。** C を入れるなら時刻で決めます。

外すなら `src/features/chat/responseSchema.ts` から落とします。`summary` で
学んだとおり、**描画しない欄を要求するとモデルはそこで考え込みます。**

### 5. 会食の距離をもう一段詰めるか

試作は「立ち姿より近い会話の距離」と書いたわりに、まだ引いています。基準の
1枚がずれると、そこから作る枚数ぶんずれます。

### 6. 口を開けた絵の開き具合

`neutral` `smile` `serious` `challenge` の4枚は、指定より大きく開きました。
4枚の間では揃っているので、直すなら4枚まとめてです。**音が鳴るように
なってから判断します。**いまは確かめようがありません。

### 7. PRD §1 と私室の距離

朝の身支度前は `docs/PRODUCT_REQUIREMENTS.md` §1 の
「not positioned as an AI girlfriend」に触ります。家でスマホを使う案は同じ
距離感を出しながら触りません。**§1 を変えるなら意図した変更として変えます。**

### 8. ツールの各タイルが何をするか

格子は `src/app/(tabs)/tools.tsx` に置きました。**格子があること自体が決定で、
中身はまだ決定ではありません。**

タイルは3状態で出しています。`ready` は実際に動くもの。`planned` はこれから
中身を決めるもの。`later` は `README.md` が v0.1 の対象外にしているものです。

押すと、なぜまだ無いのかを出します。黙って何も起きないと、社長は押すのをやめて
しまいます。見えている方が計画として機能します。

**決めるべきは `planned` の4つです。**CSVを読ませる、売上ダッシュボード、
資料を要約する、会議の準備。

売上ダッシュボードは Cloudflare D1 から読むと決まりました。`docs/SALES_DATA.md`。
