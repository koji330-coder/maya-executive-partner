## 手順

### 1. [x] `main` に取り込む（2026-09-28 済み）

自宅PCでは最新を取るだけでよい。

```
git checkout main
git pull origin main
```

### 2. [ ] 依存を入れて、テストが通ることを確かめる

```
npm ci
npm run check
cd server && npm ci && npx tsc --noEmit && cd ..
```

356件が通ればよい。落ちたら、ここで止めて原因を調べる。

### 3. [ ] サーバーを公開する（本番）

```
cd server
npx wrangler deploy
```

- DB（D1）の変更は無いので、migration は要らない（キーは既存の設定の表に暗号化して置く）
- キーの暗号化には、Gemini のキーと同じ `KEY_ENCRYPTION_KEY`（設定済み）を使う
- 出てきた **Version ID を控える**（手順7で記録する）
- 公開後、`npx wrangler tail` を開いておくと、相談ごとに `maya_turn` の行が出る。
  `"router":"off"`、`"route":"legacy"` になっていれば、OFF のまま従来どおり動いている

### 4. [ ] アプリを配信する（EAS Update）

```
npm run update:ios
```

- 端末のDBに列を1つ足している（migration 5：回答ごとの経路を保存する `route_json`）。
  アプリの起動時に自動で適用される。ネイティブの変更は無いので、ビルドは不要
- 出てきた **Update group ID を控える**

**ここから先はスマホだけでできる。**

### 5. [ ] 設定画面で TypeSafe のキーを入れる（スマホ）

1. アプリを開き直して更新を受け取る
2. 設定画面の「Jev による道具の判定」を開く。「TypeSafe のキー：未登録」と出ている
3. TypeSafe の管理画面の API キーを貼り付けて「登録」
   - サーバーが TypeSafe で使えるか確かめてから、暗号化して保存する。数秒かかる
   - 「確かめて保存しました。」と出て、「登録済み（末尾 xxxx）」に変われば完了
   - 「このキーでは Jev を呼べませんでした」と出たら、貼り間違い。保存はされていない
4. キーは画面にもサーバーの応答にも二度と出ない（末尾4文字だけ）。**チャットやファイルには貼らない**

### 6. [ ] 実機で確かめる

1. **OFF のまま**1回相談し、回答の下の「経路」が「従来」になっていること
2. ON にして、次の質問を順に試す。回答の下の「経路」を開いて見る

| 質問 | 期待する経路 |
|---|---|
| 今日の体重と食事どうだった？ | 先読み（fitlog_day）、1往復 |
| 今月Amazonでいくら売れた？ | 先読み（haksai_sales）、1往復 |
| 粗利率って何？ | データ不要、道具なし、1往復 |
| 減量中のタンパク質の目安は？ | 固定ルール（fitlog_day）。自分の体重で答える |
| 前に値上げについて何て決めたっけ？ | 候補を絞って Gemini |
| おはよう | データ不要 |

3. 経路に「従来（Jev 不通）」と出続けるなら、開いて「Jev を使わなかった理由」を見る
   （`no_key` ならキーが入っていない、`timeout` なら1秒を超えた）
4. おかしければ、**設定画面で OFF に戻せばすぐ元どおり**（公開し直しは不要）

### 7. [ ] 記録する

- `CONTENT_LOG.md` の「判定特化モデルによる Tool 選択を、切り替え式で本体に組み込んだ」の
  「成果」に、Version ID と Update group ID を書き足す（2026-09-27 の記録と同じ書き方）
- `ARCHITECTURE_GUIDE.html` の「できたこと・これから」の Jev の行を、状態に合わせて直し、
  同じアドレスへ公開し直す（`AGENTS.md` の手順）
- コミットしてプッシュ

## 使いながら見ること（急がない）

評価で見つかった点。実際の相談で起きるか、経路の表示で確かめる。

- 固定ルールが「PFCって何？」のような言葉の意味の質問にも効き、FIT LOG を読む
  （体の話かを言葉で判定しているため）。気になるなら、ルールの条件を狭める
- 会話の中にもう答えがある質問（「この数字どう思う？」など）でも、データを取り直す
- Jev が迷ったときは、応答時間のばらつきが大きい（1回 11.5秒の例あり）
- 固定ルールを足したくなったら `server/src/jevRules.ts`。設定画面の一覧にも出る
