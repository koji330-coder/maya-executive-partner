# tools

## face_frames.py — 採用しない実験

まばたきと口パクのコマを、1枚のマスター画像から幾何的に作るスクリプト。
目のアパーチャに瞼を伸ばして被せ、口は唇の線から下を列ごとにサブピクセルで
ずらして内側を描く。

**これは採用方針ではありません。**

素材制作は、別プロジェクトで実績のある既存パイプラインと Nano Banana で行う。
このスクリプトはその方針が決まる前に書いたもので、パイプラインが使えなかった
場合の退避先としてのみ残している。

分かったことは2つある。

- 目のアパーチャと口の周りさえ空いていれば、1枚のマスターから3コマずつ作れる。
  セーフゾーンの仕様（docs/ASSET_PIPELINE.md §5）はこの前提で書かれている
- 眉の上を横切る髪は、瞼の生成元になる肌に混ざると縦に伸びる。水平方向の
  メディアンで落とせるが、そもそも生成元の肌が汚れない構図のほうがよい

`maya-face-landmarks.json` は採用済みマスターの目と口の座標。
パイプライン側が同じ情報を要求する場合に流用できる。

## preview_animation.py / make_preview.py

上の実験の出力を、Talk画面と同じ表示サイズで動かして確認するためのもの。
リップシンクは `src/services/audio/clipManifest.ts` のエンベロープと
`src/features/character/LipSyncController.ts` のしきい値を移植してあるので、
アプリの判定そのものを再現している。この移植部分は方針が変わっても使える。
