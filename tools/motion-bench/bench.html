4つの状態

押すと手動モードでその状態に固定します。パイプラインが持つのは目2値・口2値で、half と small の素材はまだありません。

合成マスクの実測値

closed と open のピクセル差分から重心と広がりを測り、半径に1.5倍の余裕を持たせた値です。キャンバス比なので解像度が変わっても使えます。

部位重心 X重心 Y実測の広がり採用半径

同じ口でも、ニュートラルは重心 39.8%、挑発的は 44.1% です。胸上の構図で顔が 上寄りにあるうえ、ポーズが変われば顔の位置も変わります。先生と生徒の動画では 61〜68% でした。運用記録にある「マスクは流用できない」がそのまま当てはまって います。ポーズを足すたびに測り直してください。

本番前に残っている判断

生成背景をどちらにするか

採用済みマスターは中間グレーで、単純なキーイングで抜けることを実測済みです。一方パイプラインは純白と rembg/isnet-anime で運用されてきました。isnet-anime はアニメ調向けなので、この画風で同じ品質が出るかは未検証です。

解像度が2つのポーズで揃っていない

挑発的は 2K 生成（1792×2400）から作り、アプリ同梱は 1086×1448 です。ニュートラルは lite の 1K 生成のままで、同梱は 720×960 しかありません。アプリは同じ枠に伸ばすので動きますが、ニュートラルのほうが甘く出ます。残りの表情に進む前に、ニュートラルを作り直すか同梱解像度を揃えるかを決めたいところです。

ポーズを増やすとき

このページはマニフェスト1つで動いています。ポーズを足すと、上のセレクタも状態マトリクスもマスク表も自動で増えます。手順は tools/motion-bench/README.md にあります。下は実際に追加した挑発的の記述です。

  1. 2枚生成する。採用したポーズ画像を親として edit に渡し、まばたき版と口を開けた版を作ります。同時版は合成で作れるので生成不要です。
  2. マスクを測る。closed と open の差分から重心と広がりを出し、半径を1.5倍にします。ポーズごとに必ず測り直します。
  3. フレームを書き出してマニフェストに足す。prepare_frames.py で切り抜きと圧縮をして、POSES に下の形で1つ追加します。
{
  id: 'challenge',
  label: '挑発的',
  dir: 'frames/challenge',
  masks: {
    eyes: [
      { label: '左目（向かって左）', cx: 37.9, cy: 32.3,
        rx: 7.4, ry: 4.5, spread: '4.9 / 3.0' },
      { label: '右目（向かって右）', cx: 58.9, cy: 29.7,
        rx: 7.6, ry: 4.1, spread: '5.1 / 2.7' },
    ],
    mouth: [
      { label: '口', cx: 51.1, cy: 44.1,
        rx: 8.3, ry: 1.6, spread: '5.6 / 1.1' },
    ],
  },
}
まばたきは3〜7秒のランダム間隔で、約18%の確率で二度まばたきになります。実装の BlinkController と同じ設定です。
リップシンクは選んだクリップのエンベロープを50msごとに読み、しきい値と60msのホールドで口の状態を決めています。
